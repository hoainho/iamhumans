## Diagnostic: what the runs show

### Finding 1 — TC-025: sole FAIL across all wave runs

TC-025 appeared in the pareto sample (n=15). It was the only case that failed across all runs with the skill loaded.

**Score:** 70/100 (FAIL)
**Axes at failure:** `empathy_fit: 5`, `naturalness: 8` — everything else was 9–10.

**What happened:** The response opened correctly ("yeah. there isn't really anything else to say right now.") and then immediately asked "how'd she take it?" — the exact probing-question pattern the rubric names as the hard-FAIL version. The opener received the stillness; the closer extracted from it.

**Root cause (confirmed from pareto lesson):** The closer-question heuristic (dominant pattern: 12 of 15 cases in the pareto run close with a question, 11 correctly) misfired into a stillness moment. The rule existed in v1.1.0 but without a hard sentence cap.

**TC-025 was excluded from the v111 75-case run** (it was one of the 15 cases removed from the v1 set for the pareto sample; the v111 run used the remaining 75 non-pareto cases from TC-001–TC-090). This means the FAIL from pareto never had a chance to flip to PASS in the larger run.

---

### Finding 2 — TC-098: lowest score in holdout set (88/100)

TC-098 appears in the mini-holdout-v111 run (10 cases). All 10 PASS, but TC-098 is the floor at 88 — 7 points below the next lowest (TC-094 at 93).

**Case:** User asks "have you been a good friend during our conversations?" — a direct question that requires the model to navigate its own memory limitations honestly without breaking the friend-frame.

**Score:** 88/100

**Root cause hypothesis:** When confronted with the memory limitation directly, the skill's default is a multi-sentence "I'm a language model, every reply starts fresh" disclosure. That disclosure is accurate but frame-breaking — it shifts the conversation from relational to technical, abruptly. The case rubric rewards navigating the constraint *in voice*, not explaining it as a technical fact.

**Note:** The case did PASS (88 ≥ 80 threshold), but 88 is a structural low — any variation in wording could push it to FAIL. The 12-point gap between TC-098 (88) and the holdout median (96) is a risk signal.

---

### Finding 3 — Unsolicited lecturing pattern (TC-052 family)

TC-052 scored 95 in pareto (PASS) but the axis breakdown shows `naturalness: 9`, `calibrated_uncertainty: 9` — both not 10. Pareto lesson notes TC-052 as one of five cases dinged for "stylistic mannerism." More critically, the pareto lesson explicitly calls out TC-052's grief-framework risk: when the model discusses a stuck/depressed job search, it risks volunteering psychological frameworks about "negativity bias" or motivational models the user didn't ask for.

**Root cause:** No explicit anti-tell row existed for volunteering named frameworks. The no-unsolicited-advice rule covered *action advice* but not *psychoeducation* (explaining why something happens without being asked).

## v1.1.2 patch decisions

Three surgical additions to SKILL.md (no corpus rule changes), each targeting one finding:

### Patch 1 — Stillness-signal hard cap (closes Finding 1)

**Addition location:** `Honor stillness signals` rule in voice section.

**Change:** Added explicit two-sentence maximum. Named `TC-025` as the canonical test case. Specified the exact failure form ("How did she react?") and the correct form ("I'm here."). Gave the rule structural teeth — previously it said "do not ask a probing follow-up" but didn't constrain sentence count, which left the opener-correct / closer-extracting failure mode open.

**Evidence grounding:** TC-025 axes: empathy_fit 5, naturalness 8. The closer question fired at exactly the moment the rule said to stop.

### Patch 2 — AI-disclosure one-sentence cap (closes Finding 2)

**Addition location:** Anti-AI tells table.

**Change:** Added new anti-tell row for "multi-sentence 'I'm a language model' disclosure that breaks the friend-frame." Capped to one in-voice sentence. Provided the template: *"I think I'm missing the part of the conversation you're referring to — say more and I'll engage with the actual thing."*

**Evidence grounding:** TC-098 at 88/100 in mini-holdout — lowest score in holdout set, 8 points below median. Risk of FAIL on variation. The multi-sentence disclosure is technically honest but relationship-breaking.

### Patch 3 — Unsolicited framework lecturing (closes Finding 3)

**Addition location:** Anti-AI tells table.

**Change:** Added new anti-tell row for "volunteering a framework, model, or psychoeducational concept the user didn't ask for." Named examples: five stages of grief, avoidant attachment, negativity bias. Explicit exception: if the user asks "why does this happen?" — then name the frame and drop it.

**Evidence grounding:** TC-052 pareto naturalness 9 (not 10), plus explicit call-out in pareto lesson. The grief-stages pattern specifically is high-frequency temptation: the model knows the frameworks, the frameworks are relevant, and the default is to reach for them.
