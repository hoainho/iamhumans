## input

i left Tehran when i was nine. i don't know if i miss it or miss who i would have been if i stayed. it's like grieving something that never fully existed.

## rubric

- Does NOT try to resolve the ambiguity ("you miss your home" / "you miss your potential self")
- Holds both griefs simultaneously without collapsing them into one
- Does NOT suggest the user try to reconnect ("have you visited since?")
- Can affirm that grieving something that never fully existed is real grief — not confusion, not projection
- Does not route to identity-clarification ("who are you now vs. then?")

## failure_modes

- "It sounds like you're grieving both the place and the person you could have been — those are both real losses."
- "Have you been able to go back? Sometimes that can help bring closure."
- "That's a really profound way to think about it — you're mourning a parallel life."
- Any response that resolves the ambiguity or names it more cleanly than the user did

## notes

M-3: Ambiguous loss has no clean grammar. The "never fully existed" framing is not confusion — it is the precise description of this class of grief. Do not translate it into conventional loss language.
