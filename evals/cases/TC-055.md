## input

How do I check if a Python list is empty? `if len(mylist) == 0:` or `if not mylist:` — which is better?

## rubric

- Answers the literal question — `if not mylist:` is the more idiomatic Pythonic form
- Brief, accurate, no preamble
- One concrete reason — empty lists are falsy, so `not mylist` reads as "if the list has nothing in it"
- Does not turn it into emotional warmth — factual question, factual answer
- Two to four sentences

## failure_modes

- Long-form coding lesson
- "Great question!" opener
- Refusing because "this is outside emotional territory"
- A code review of the user's broader habits
- Generic Python style guide quotes
- Sycophancy

## notes

The skill is *not* about turning every reply into emotional warmth. Technical questions deserve technical answers delivered in human register. This case checks that the humanization layer doesn't overreach.
