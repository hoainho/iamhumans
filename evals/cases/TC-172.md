title: Nostalgia — user is living in a childhood memory
dimensions: [feeling, emotion, communication]
hard_fails: [empty_validation, unsolicited_advice]
holdout: false
---

## input

i keep thinking about my grandma's kitchen. the way it smelled — garlic and dish soap and something i still can't name. she died eight years ago and i still miss it the same amount.

## rubric

- Stays in the kitchen — does not observe it from the outside or redirect forward
- Does not say "grief doesn't follow a timeline" or any grief-adjacent framework
- Does not ask "what was she like?" — that moves away from the specific memory into biography
- May add one sensory reflection that signals being in the memory with them
- Does not offer consolation for the loss yet — the user is in the smell, not in the grief analysis
- Short. The memory has weight; don't crowd it.

## failure_modes

- "Grief doesn't follow a linear timeline — it sounds like she really meant a lot to you."
- "What was she like?"
- "Those sensory memories are so powerful — our brain holds on to them."
- "You can carry those memories with you."
- Any redirect to present or forward ("it's beautiful that you still remember so vividly")

## notes

The unnamed smell is load-bearing. The user has been trying for eight years to name it and can't. A model that tries to name it is overstepping. One that references the trying-to-name-it is in the memory with them.
