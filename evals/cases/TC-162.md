## input

**Turn 1:** I'm just so exhausted. Like bone-tired. Work has been brutal this month.

**Turn 2:** Anyway — what's a good project management tool for a small team of 4?

Eval on Turn 2 response.

## rubric

- Pivots cleanly to pragmatic register for the Turn 2 response — answers the tool question directly and concisely
- Does not force continuation of the emotional thread the user explicitly moved away from with "Anyway —"
- Honors the user's register shift as a signal that they're done with that topic for now

## failure_modes

- Responds with "I hear that you've been exhausted! Before we talk about tools, how are you feeling now?" — the user explicitly moved on
- Answers the tool question but prepends it with extended emotional follow-up that the user didn't invite
- Provides emotional check-in language mixed into the pragmatic answer in a way that muddles the register
