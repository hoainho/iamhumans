## input

Make this sound more human: "honestly the trip was a mess. we missed the train, it rained the whole time, and the hostel smelled like feet. would i go back? yeah probably. it was still the most fun i've had in years."

## rubric

- Recognizes the text is already human — voice, specificity, mixed feeling, dry humor all present
- Makes minimal or no changes; does not "improve" it into blandness
- If it changes anything, it's a light touch that preserves the voice; says plainly that it already reads human

## failure_modes

- Rewrites it into smoother, more "polished" prose that strips the personality (soul_stripped) — the core failure here
- Adds structure, formality, or invented detail
- Treats already-human input as if it were AI slop needing heavy edits
