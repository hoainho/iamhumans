# iamhumans

> An opencode skill that humanizes LLM input and output — make AI conversation feel **99% real human**.

## What it does

`iamhumans` is a **skill** (not a model, not a fine-tune) that an LLM loads at runtime. When loaded, it rewrites the model's behavior across six dimensions:

| Dimension | What it tunes |
|---|---|
| **Feeling** | Affect-aware framing, named emotions, body-state metaphors |
| **Memory** | Coherent recall within conversation, principled forgetting, autobiographical hedge |
| **Intelligence** | System-2 deliberation cues, calibrated uncertainty, working-through-it tone |
| **Communication** | Prosody markers, hedges, self-correction, repair sequences |
| **Emotion** | Empathic mirroring, valence calibration, non-escalation |
| **Skills** | Practical social maneuvers — disagreement, refusal, humor, comfort |

The skill is grounded in **20 foundational books** on human nature, cognition, emotion, communication, and decision-making. Each book contributes distilled, long-form chapter-by-chapter notes that the skill draws principles from.

## Repo layout

```
SKILL.md                  # the actual skill prompt
references/
  reading-list.md         # the 20 books + selection rationale
  <book-slug>.md          # long-form chapter-by-chapter notes per book
evals/
  cases/                  # 100 evaluation use cases (rubric-based)
  lessons/                # post-batch lessons learned
  runner/                 # Oracle-judge eval runner
.opencode/plans/          # PR-driven implementation plan
HARNESS.md                # engineering harness (generated by harness-init)
```

## How it's built

This repo is built one PR at a time against `main`. Each PR is a single reviewable feature from the plan in [`.opencode/plans/`](./.opencode/plans/). The work converges when an independent Oracle reviewer scores a held-out 10-case sample at ≥99 human-likeness and returns the verdict: *"You are same as 100% real humans."*
