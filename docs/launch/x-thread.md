# X thread — iamhumans v3.0

1/ Most "make the AI warmer" hacks work on the surface. iamhumans works on the shape underneath — when to be short, when to sit with something, when the right reply is just "oh."

A portable skill for Claude Code, opencode & any agent. 🧵

2/ Two modes:
• Mode A — conversational presence (the model *is* the friend)
• Mode B — composition / de-AI: paste AI-drafted prose, get it back human, in your voice.

3/ The keystone: a self-audit pass on every reply — detect AI-tells → repair → soul check. A tell-clean but sterile draft fails. Stripping is necessary; soul is the point.

4/ Measured, not asserted: a blind oracle scored a 30-case sample at 82.7/100, 27/30 PASS, 0 hard-fails. Mixed edges shown, not hidden. (A sample — not the full 429-case harness yet.)

5/ It's one SKILL.md. No runtime. Drop it into ~/.claude/skills, symlink it into opencode, or paste it into any system prompt.
