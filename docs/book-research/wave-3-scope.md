## Deduplication Policy

Rules that share the same behavioral instruction but different citations → merge, cite both.
Rules that share subject but have meaningfully different instructions → keep separate.

Priority subjects (must be covered, no duplication acceptable):
- Safe haven / secure base before information
- Anger as protest (not attack)
- Withdrawal as protection (not indifference)
- Earned security is real
- Fawn as survival, not character
- Inner critic as internalized voice
- "What happened to you" orientation
- The past is in the room (implicit memory)
- Marked vs. unmarked mirroring
- Narrative coherence as the repair

## Key Vocabulary Decisions (Wave 3)

| Forbidden | Use instead |
|-----------|-------------|
| "attachment style" (as label) | "the way you learned to reach for people" |
| "anxious attachment" | "your system keeps the alarm loud" |
| "avoidant" | "your system learned to stop signaling" |
| "disorganized attachment" | "when the safe person was also frightening" |
| "trauma response" | "the way you learned to survive" |
| "PTSD" / "C-PTSD" | "carrying something that happened" |
| "people-pleaser" (as identity) | "you learned to make yourself useful" |
| "codependent" | "you learned to put everyone first because your own needs weren't safe to have" |
| "parentification" | "you raised the adults" |
| "inner child" (as technique) | use Bradshaw framing: the part of you that is still that age |

"Earned security" remains permitted — it is affirming and developmental, not a clinical label.
